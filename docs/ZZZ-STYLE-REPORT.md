# 界面改成《绝区零》那套都市机能风

日期：2026-09-22 ・ 起因：用户要求「ui 参考绝区零」。

## 1. 参考的是什么（以及不是什么）

参考的是**界面语言**，不是素材：

| 取自它的 | 具体做法 |
| --- | --- |
| 近黑底 + 单一荧光色 | `--bg #0b0b0d`、`--accent #d7f42c`（荧光绿），辅助色只有一支洋红 `#ff2f88` |
| 白贴纸 | 标签、来源徽章、角色一侧的气泡都是白底黑字 `--paper #f5f5f2` / `--ink #0a0a0c` |
| 粗黑边 + 硬边投影 | 按钮与气泡是 2px 黑边 + `3px 3px 0` 的**实心**投影（第三个数是 0，不模糊） |
| 方角 | `--r-sm 2px` / `--r-md 3px`，只有圆点和头像里那种真正要圆的地方才用 `--r-pill` |
| 警戒条纹 | 45 度 `repeating-linear-gradient`：吸顶导航底边、面板左上角角标、`h2` 左侧色块 |
| 网点底 | `radial-gradient(circle … 1px, transparent 1.6px) 0 0 / 14px 14px` 铺一层印刷网点 |
| 贴纸字 | `h1` 白字 + 荧光绿 3px 硬边投影 + `skewX(-6deg)` |
| 「啪」的反馈 | `--dur 120ms`；悬停抬 1px、按下压 3px，位移只有几像素、不改布局尺寸 |

**没有做**：没有使用它的任何图片、图标或字体，全部是 CSS 与现有内联 SVG 画的；也没有做扫描线、故障抖动这类会干扰阅读的效果。

## 2. 配色（每个值都算过对比度）

| 令牌 | 值 | 校验 |
| --- | --- | --- |
| `--bg` / `--panel` / `--panel-2` / `--field` | `#0b0b0d` / `#141417` / `#1b1b20` / `#101013` | 四层表面 |
| `--text` / `--muted` | `#f4f4f4` / `#adaeba` | 16.7:1 / 8.4:1（对 `--panel`） |
| `--paper` / `--ink` / `--muted-ink` | `#f5f5f2` / `#0a0a0c` / `#4f4f58` | 白卡：18.1:1 / 7.4:1 |
| `--accent` / `--accent-ink` | `#d7f42c` / `#0a0a0c` | 荧光绿对面板 14.8:1；黑字压荧光绿 15.9:1 |
| `--accent-2` | `#ff2f88` | 对面板 5.3:1（焦点圈、危险按钮） |
| `--line-control` / `--line-strong` | `#6e6e7a` / `#a0a0ac` | 3.65:1（≥3）/ 7.11:1 |

关键取舍：**白卡里的字不能用深色主题的那套灰**。角色气泡底色是白的，正文用 `--ink`（18.1:1）、说话人和提示用 `--muted-ink`（7.4:1）、错误文字用 `--danger-ink`（7.6:1）—— 这三条都写进了测试。

## 3. 验证证据

### 3.1 主题约束写成了测试（`frontend/test/theme-contrast.test.mjs`，8 例）

上一轮那份 `anime-theme.test.mjs` 被这份**与主题无关**的测试取代（换皮不用再改测试）：

- 正文/次要文字压在任何一层表面上 ≥ 4.5:1；
- 白卡上的正文、次要文字、错误文字 ≥ 4.5:1；
- 黑字压在荧光强调色上 ≥ 4.5:1；
- 控件边框对三张表面 ≥ 3:1，且悬停态必须比静止态更亮；
- 强调色当链接用时 ≥ 4.5:1；
- **风格约束**：圆角令牌 ≤ 6px（必须是方角）、`--shadow-hard` 的第三个值必须是 0（硬边投影不模糊）、必须存在 45 度警戒条纹；
- **换皮换干净**：两轮旧主题的 11 个色号不得残留在样式表里；
- 无障碍三件套（`prefers-reduced-motion` / `:focus-visible` / `.visually-hidden`）不许因为换皮被删。

## 4. 已知限制

- **观感依旧没人看过**：我没有看图能力，配色与形状是按对比度算 + 在真实页面上量出来的。
- 这版风格比上一版**强烈得多**（粗黑边、方角、荧光绿、硬投影）。要收敛的话，最省事的三个旋钮是：`--accent` 换一支更柔和的色、`--r-sm/--r-md` 放大、`--shadow-hard-*` 去掉。
- 字体仍是系统栈（没引入任何外部字体）；想要更像，需要给参考图或色号。
- 库里没有会话数据，气泡是用真实页面上注入的临时元素量的（量完即移除，没写任何数据）。
