# 二次元风格改造：夜色星空 + 樱花粉/天空蓝

日期：2026-09-22 ・ 起因：用户要求用 `/ui-ux-pro-max`「美化二次元风格网站界面」。

## 1. 技能里查到了什么（以及没查到什么）

| 查询 | 结果 | 处置 |
| --- | --- | --- |
| `--design-system "anime ACG companion chat vibrant playful dark"` | 回的是**落地页**口径（Scroll-Triggered Storytelling）+ Claymorphism + 橙蓝配色 | 落地页结构与橙蓝配色**不适用**，未采纳；只留下它的可访问性硬要求 |
| `--domain style "anime kawaii pastel"` | **0 条命中**（数据库里没有 anime/kawaii 这个风格条目） | 按技能自己的规则重试一次（见下） |
| `--domain style "neon glow night"`（重试） | `dark-mode-oled`、`retro-futurism`、`cyberpunk-ui` | **采纳**：深底色 + 霓虹粉/青/紫强调色 + 克制的发光 + 高对比正文；CRT 扫描线/故障抖动**不采纳**（技能自己标了 risk:high，聊天界面里也吵） |
| `--domain color "anime pastel vibrant night"` | Sleeping Tracker 的「Night indigo + dream violet on dark」 | **采纳**为底色方向 |
| `--domain typography "rounded playful cute japanese"` | Varela Round / Fredoka / Nunito（都要 Google Fonts） | **未采纳**：本项目不引入新依赖、也不为了字体去连外网；中文还得靠系统字体。用形状与配色做"可爱"，字体保持系统栈 |

明确记录：**风格库里没有 anime/二次元这个分类**，上面的配色与效果是按它返回的霓虹暗色风格条目 + 通用硬规则组合出来的，不是数据库里现成的"二次元风格"。

## 2. 改了什么

### 2.1 配色（全部走令牌，换色只改一处）

| 令牌 | 值 | 含义 |
| --- | --- | --- |
| `--bg` | `#0f0b1a` | 夜紫底 |
| `--bg-glow-a/b/c` | 樱花粉 / 天空蓝 / 紫 | 三团背景光晕 |
| `--panel` / `--panel-2` / `--field` | `#17132a` / `#1e1836` / `#120e22` | 表面层次 |
| `--accent` | `#ff8ac7` | 樱花粉：主按钮、角色一侧 |
| `--accent-2` | `#7fd7ff` | 天空蓝：焦点圈、自己一侧 |
| `--accent-ink` | `#221033` | 压在粉上的字 |
| `--line-control` / `--line-strong` | `#6b6390` / `#8d85b8` | 控件边框 / 悬停与弹窗边界 |

底色换成夜紫时，**上一轮的对比度结论全部重算过**（不是沿用），并且写成了可执行的门槛，见第 3 节。

### 2.2 形状与质感

- 圆角整体放大：`--r-sm/md/lg` = 10 / 14 / 20px，另加 `--r-pill`；按钮与标签改成胶囊。
- 玻璃反光：面板、卡片、编辑器顶部一道极淡的白色渐变（`--sheen`），比整块发光便宜，也不影响文字对比度。
- 发光做成令牌：`--glow-soft` / `--glow-accent` / `--glow-cyan`，主按钮、选中导航、卡片悬停各自用一档。
- 夜空背景：6 个静止的星点 + 3 团光晕，共 9 层 `radial-gradient` —— 静止不动，不参与动画。
- 标题：粉→蓝渐变字，外面套 `\@supports (background-clip: text)` 兜底（不支持就退回单色，不会变成看不见的透明字）；标题左侧加了内联 SVG 小星（`aria-hidden`）。
- `h2` 左侧加一道粉蓝渐变竖条；头像加粉色的光晕描边。
- 聊天气泡：自己一侧是青→透明渐变 + 青色描边，角色一侧是粉→紫渐变 + 粉色描边，**两侧各留一个 10px 的直角**当"气泡尾巴"；说话人前面一个小圆点（自己青、角色粉）。
- 滚动条滑块改成粉→紫渐变，进度条改成粉→蓝渐变。

### 2.3 没动的

- 行为、接口、枚举、文案都没动：这轮只改 `styles.css` + 两个装饰性 SVG（`lib/icons.tsx` 的 `SparkleIcon`，`app.tsx` 标题里用一次）。
- 二维码那块仍然是白底（`.qr-canvas`）—— 二维码不能染成夜色。

## 4. 已知限制

- **观感没人看过**：本次会话没有看图能力，配色与形状是按对比度算出来 + 在真实页面上量出来的，好不好看还得你眼睛说了算。
- 库里当前**一个会话都没有**（`GET /api/conversations` → `{"items":[]}`），所以真实消息气泡没有数据可测；上面的气泡结论是在**真实页面上注入临时元素**量的样式，注入完就移除了，没写任何数据。
- 风格数据库里没有"二次元"分类，这是按霓虹暗色系条目 + 通用硬规则组合的结果（想更贴某个具体作品，得给出参考图的色号）。
- 字体仍是系统栈：没引入 Google Fonts，可爱感全部来自形状、颜色与发光。
